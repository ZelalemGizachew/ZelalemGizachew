## 05 // PROBLEMS I LIKE

I tend to gravitate toward software where the edge cases are the product:

- transaction and fintech infrastructure
- concurrency, retries, idempotency and failure recovery
- distributed/backend architecture
- background execution and state reconciliation
- realtime media and voice-agent pipelines
- developer platforms, SDKs and integrations
- automation that removes operational work
- security/privacy boundaries that must survive production
- interfaces that make complicated machinery feel simple

> **The target:** become the engineer you call when the system is important, messy, distributed, time-sensitive, or slightly unreasonable.
